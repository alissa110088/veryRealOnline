# 🕵️ Hide & Seek Online

A multiplayer hide & seek game prototype where players can interact with and move objects in the environment to hide or find others.

## 🎮 About the Game

*Hide & Seek Online* is a small multiplayer experiment where players are split into two roles: seekers and hiders.

Hiders can manipulate objects in the environment to create hiding spots, while seekers must find them before time runs out.

The game also includes a simple lobby system to allow players to connect and start matches together.

## 🧠 Core Idea

This project focuses on:
- emergent gameplay through physics interaction
- player-driven hiding strategies
- simple but fun multiplayer interactions

## 🛠️ Features

- Multiplayer hide & seek gameplay
- Object interaction system (move / push objects)
- Basic lobby system for matchmaking
- Player roles: Seeker vs Hider
- Physics-based environment interaction

## ⚙️ Built With

- Unity
- C#
- Networking solution (simple lobby system)

## ⏱️ Development

- Developed as a prototype
- Focused on multiplayer systems and interaction mechanics
- Built to explore emergent gameplay in online environments

## 🎯 Goal of the Project

The goal was to experiment with:
- simple multiplayer architecture
- environmental interaction systems
- fun player-driven hiding mechanics
